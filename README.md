# Regression Model Comparison: Linear, Lasso & Ridge

This project focuses on building and comparing **Linear Regression, Lasso Regression, and Ridge Regression** models for a regression problem. The workflow includes data preprocessing, handling missing values and outliers, feature encoding, feature scaling using **StandardScaler**, model training, prediction, and evaluation.

The models are evaluated using **Mean Squared Error (MSE), Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R-squared (R²)** to understand their prediction performance.

### Models Compared
- Linear Regression
- Lasso Regression
- Ridge Regression

### Evaluation
The models achieved an R² score of approximately **0.63**, with Ridge Regression providing a slightly better performance among the three models.

### Technologies

### Key Learning
This project demonstrates how preprocessing, feature scaling, regularization, and model evaluation can be used to build and compare regression models and select an appropriate model based on performance.
